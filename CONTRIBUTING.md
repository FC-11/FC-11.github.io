# Contribuire a My quizzbando

Grazie per l'interesse verso My quizzbando! Se vuoi aiutarmi a migliorare l'applicazione o il sito web, ecco come puoi fare:

## Segnalare Bug o Errori nei Quiz
Se riscontri un problema nell'app o nel sito:
1. Vai nella scheda **Issues** in alto in questo repository.
2. Clicca sul pulsante verde **New Issue**.
3. Descrivi chiaramente l'errore che hai trovato.

## Suggerire Nuove Funzionalità
Hai un'idea per una nuova funzione o per un nuovo tipo di quiz? Apri una **Issue** spiegando nel dettaglio la tua proposta. Grazie per il supporto!
